# KG-LSCR：融合知识图谱与法律三段式推理的交通刑事案情分析方法

本仓库用于公开论文《融合知识图谱与法律三段式推理的交通刑事案情分析方法》的相关程序、实验脚本与结果文件。

KG-LSCR 面向交通肇事罪与危险驾驶罪相关案件，结合三态事实抽取、局部案件图谱、拓扑主干查询、规范—经验双通道检索与法律三段论结构化推理，开展案件事实与法律适用分析。

> 完整工程位于 `KG-LSCR-Benchmark/` 子目录。仓库根目录中的 `main.py` 和 `sample_output.json` 为早期演示文件。运行完整工程时，请先进入 `KG-LSCR-Benchmark/` 目录。

## 1. 方法组成

| 模块 | 名称 | 功能 |
|---|---|---|
| TFE | 三态事实边界抽取 | 将事实要件标注为“明确存在、明确不存在、信息不足”，并组织主体与行为的归属关系 |
| TBM-SR | 局部案件图谱拓扑主干映射 | 从局部案件图谱中组织核心事实，构建检索查询 |
| DC-IRAG | 规范—经验双通道隔离检索 | 分别检索法律规范与历史类案，区分规范依据和经验参考 |
| LS-CoT | 法律三段论结构化推理 | 按照“规范识别—事实确认—法律涵摄—结论生成”组织分析结果 |

总体流程：

```text
案件事实文本
    │
    ▼
三态事实抽取与主体归属
    │
    ▼
局部案件图谱构建
    │
    ▼
拓扑主干映射与查询生成
    │
    ├── 法规规范通道检索
    │
    └── 历史类案通道检索
    │
    ▼
法律三段论结构化推理
    │
    ▼
案件分析结果
```

## 3. 环境准备

下载本仓库后，进入完整工程目录：

```bash
cd KG-LSCR-Benchmark
```

安装工程依赖：

```bash
python -m pip install -r requirements.txt
```

模型名称、接口地址、数据路径及其他实验参数在以下文件中配置：

```text
configs/config.py
```

运行前应检查该文件中的配置，使其与本地数据位置和模型部署方式一致。

如果使用外部模型服务，应按照实际代码读取的环境变量或配置项设置接口凭证。不要将真实 API 密钥提交到仓库。

## 4. 运行入口

以下命令均在 `KG-LSCR-Benchmark/` 目录下执行。所需参数和资源路径以对应脚本及配置文件中的实现为准。

## 5. 数据来源

论文实验使用全国司法大数据挑战赛公开数据集 CAIL2018。

官方仓库：

https://github.com/china-ai-law-challenge/CAIL2018

本仓库不重复分发 CAIL2018 原始数据。数据下载、使用及引用应遵循原项目的相关说明。

论文涉及以下数据资源：

| 资源 | 规模 | 用途 |
|---|---:|---|
| Test-2000 | 2,000 件 | 交通刑事案件测试 |
| 历史类案库 | 10,000 件 | 历史类案检索 |
| 法规规范库 | 13 条核心条文 | 法律规范检索 |
| gold100 | 100 件 | 人工复核、细粒度评价与消融分析 |

其中，Test-2000 包括交通肇事罪和危险驾驶罪各 1,000 件。历史类案库从 CAIL2018 训练语料中选取。

法规规范库中的“13 条核心条文”与事实抽取模块中的“13 类事实要件”是不同概念。

## 6. 数据预处理

论文报告的数据处理流程包括：

1. 筛选交通肇事罪与危险驾驶罪的单一罪名候选案件；
2. 剔除少于 50 字的短文本记录；
3. 过滤包含“本院查明”“本院认为”等预设表达的记录，以减少潜在裁判信息泄漏；
4. 根据语义指纹去重；
5. 分别抽取两类案件各 1,000 件，构建平衡测试集。

清洗统计如下：

| 阶段 | 交通肇事罪 | 危险驾驶罪 |
|---|---:|---:|
| 初始候选案件 | 2,649 | 7,972 |
| 剔除短文本记录 | 25 | 46 |
| 剔除潜在信息泄漏记录 | 149 | 132 |
| 剔除重复文书 | 12 | 51 |
| 清洗后候选案件 | 2,463 | 7,743 |
| 最终测试集 | 1,000 | 1,000 |

仅获取原始数据不能保证得到完全相同的实验划分。精确复现需要一致的数据版本、清洗参数、去重配置和最终样本标识。

## 8. 评价指标

| 指标 | 含义 | 方向 |
|---|---|---|
| Macro-F1 | 罪名判定宏平均 F1 | 越高越好 |
| MAP | 法条推荐平均精度均值 | 越高越好 |
| Attrib-Acc | 主体归属准确率 | 越高越好 |
| FHR | 事实虚构与幻觉率 | 越低越好 |
| SVS | 三段论推演合规分 | 越高越好 |
| NCR | 规范冲突率 | 越低越好 |
| MAE | 量刑平均绝对误差，单位为月 | 越低越好 |
| Recall@1 / Recall@3 | 指定检索位置范围内的法条召回指标 | 越高越好 |
| CVR | 法条引用合规性指标 | 越高越好 |
| CDIS | 规范—经验隔离度指标 | 越高越好 |

自定义指标的统计单位、分母、评分规则及人工复核要求，应结合论文评价协议和实际评价代码理解。

## 13. 复现范围

快速示例用于检查方法流程与输出结构，不等同于完整论文实验复现。

复现论文结果需要准备：

- 对应版本的 CAIL2018 数据；
- Test-2000 样本划分及 gold100 标注；
- 法规条文内容与适用版本；
- 历史类案库及检索索引；
- 模型权重或模型服务；
- 提示模板、运行参数及评价协议。

各方法的实现范围以源码为准。基线文件名不表示其已经完整复现对应原论文或官方系统。
