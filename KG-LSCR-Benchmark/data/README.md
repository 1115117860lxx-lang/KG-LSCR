# Dataset Description (数据集说明)

本目录包含用于评估交通刑事司法案情智能分析的权威评测数据集：

### 1. `sample_cases.json` (50 件精选平衡测试样例)
- **用途**：供快速验证与本地无需 GPU 快速复现演示。
- **构成**：交通肇事罪 25 件、危险驾驶罪 25 件，涵盖自首、赔偿、逃逸阻断、同名主体交错等典型司法案情。

### 2. `cail2018_traffic_test_2000.json` (2,000 件全量测试基准集)
- **来源**：全国司法大数据挑战赛公开数据集 **CAIL2018**。
- **预处理与无泄漏脱敏**：
  1. 筛选案例文书为交通肇事罪与危险驾驶罪（各 1,000 件）；
  2. 剔除全文少于 50 字的残缺文书；
  3. 基于正则表达式严格过滤案情文本中包含“本院认为”、“本院查明”等直接披露裁判结果的剧透文本；
  4. 采用 MD5 文本语义指纹严格去重。

### 3. `law_library.json` (13 条交通犯罪核心刑法规范库)
- 涵盖《刑法》第 133 条各款（基本犯、逃逸加重犯、逃逸致死犯）、第 133 条之一（危险驾驶罪）、第 67 条第一款（自首）以及最高人民法院相关交通犯罪司法解释。

### 4. `gold100_sample.csv` (100 件专家人工复核黄金评价集)
- 针对同名主体交织、被害人自身过错、送医抢救排除逃逸等高争议疑难案件进行人工细粒度法理要素标注，用于评估事实主体归属率 (Attrib-Acc) 与三段论合规分 (SVS)。
